  • Reduces repeat gas loss
  • Performance verified after service
Request Service Call Now

How it works

1. Pressure Check

Current refrigerant pressure is checked against the unit's specification.

2. Leak Detection

If pressure is low, we look for the source of the leak before topping up gas.

3. Gas Charging

Correct refrigerant type is charged to the specified pressure.

4. Verification

Cooling performance is checked after charging.
